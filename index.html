01Kit de génération

Le kit décrit ce qui reste identique sur toutes les pages : style graphique, format, règles de composition, ce qu'il faut éviter. Il est envoyé avec chaque page. Format JSON — télécharger un exemple.

02Personnages

Les images sont conservées dans ce navigateur (IndexedDB) : tu ne les téléverses qu'une fois. Chaque page référence un personnage par sa clé (ex. camille).

Glisse ou choisis une ou plusieurs images de personnages.

03Fiches de lieux (optionnel)

Décris chaque lieu récurrent (décor, couleurs, meubles) pour garder une continuité visuelle. Une image de référence est facultative mais recommandée si un lieu revient souvent.

04Import des pages

Format JSON (tableau d'objets id, characters, location, context, prompt — exemple) ou feuille Excel/CSV avec les colonnes id | characters | location | context | prompt (personnages séparés par des virgules).

L'import ajoute les nouvelles pages et met à jour le contenu des pages existantes (même id) sans toucher à leur statut déjà généré.
